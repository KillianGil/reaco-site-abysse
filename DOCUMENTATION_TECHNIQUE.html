ABYSSE

Documentation Technique du Projet

Présentation du Projet

ABYSSE est le site web officiel d'un musée maritime fictif situé à Toulon. Ce projet a été développé dans le cadre d'un projet scolaire REACO. Il s'agit d'une plateforme web moderne et immersive, proposant une expérience utilisateur premium avec une scène 3D interactive, un système complet de gestion de contenu, et une identité visuelle inspirée des fonds marins.

Page d'Accueil - Expérience 3D Immersive

La page d'accueil propose une plongée visuelle dans l'univers sous-marin grâce à une scène 3D complète :

  • Modèle 3D de sous-marin navigable avec contrôle de caméra
  • Environnement océanique complet : brouillard, lumière volumétrique, caustiques
  • Faune marine animée : bancs de poissons, méduses, raies manta, poissons des abysses
  • Effets visuels : particules bioluminescentes, neige marine, rayons de lumière
  • Algues et décorations procédurales avec mouvement naturel
  • Overlay d'informations avec présentation du musée et CTA

Page Actualités

  • Liste des articles avec pagination et animations au scroll
  • Section "À la Une" pour les articles mis en avant
  • Filtrage par catégorie : Événements, Découvertes, Vie du musée
  • Cartes interactives avec aperçu image, date, résumé
  • Newsletter avec champ d'inscription

Page Article Détail

  • Affichage du contenu complet avec typographie optimisée
  • Image de couverture en grand format
  • Boutons de partage social : X (Twitter), Facebook, LinkedIn, Instagram, Copier le lien
  • Articles similaires suggérés en bas de page
  • Navigation : retour aux actualités

Page Informations Pratiques

  • Comment venir : À pied, en bus, en voiture avec coordonnées GPS
  • Horaires d'ouverture avec durée de visite recommandée
  • Grille tarifaire : Adulte (16€), Jeune (10€), Enfant (8€), Famille (42€)
  • Services du musée : Accessibilité PMR, audioguides multilingues, cafétéria, boutique, Wi-Fi, consignes
  • Animations au scroll avec compteurs animés

Page Contact

  • Formulaire de contact fonctionnel (EmailJS) : nom, email, sujet, message
  • Informations de contact : adresse, téléphone, email
  • Carte interactive iframe Google Maps
  • FAQ accordéon : 6 questions fréquentes avec réponses détaillées
  • Feedback visuel : états de chargement, succès, erreur

Page Visiter

  • Présentation du parcours de visite
  • Espaces thématiques du musée
  • Informations pratiques complémentaires

Page Partenaires

  • Logos des partenaires institutionnels et privés
  • Présentation des collaborations

Interface d'Administration

Espace sécurisé par mot de passe pour la gestion complète du contenu :

  • Dashboard : statistiques (nombre d'articles, à la une, publications du mois)
  • Gestion des articles : création, modification, suppression avec éditeur complet
  • Upload d'images : drag & drop, compression automatique via Cloudinary
  • Gestion des catégories : CRUD complet avec personnalisation des couleurs
  • Mise en avant : toggle pour afficher un article en "À la Une"
  • Événements : champs optionnels date/heure pour les événements
  • Recherche et filtrage dans la liste des articles

Effets Visuels

  • Glassmorphism : Effets de flou sur les cartes et overlays
  • Dégradés animés : Arrière-plans dynamiques
  • Animations GSAP : Déclenchées au scroll (ScrollTrigger)
  • Micro-interactions : Hover, tap avec Framer Motion
  • Smooth scroll : Navigation fluide avec Lenis

Responsive Design

Breakpoint Taille Adaptations
Mobile < 768px Menu burger, disposition 1 colonne, navbar simplifiée
Tablette 768px - 1024px Disposition 2 colonnes, navigation hybride
Desktop > 1024px Disposition 3 colonnes, sidebar admin complète

Sécurité

  • Variables d'environnement : Clés API stockées dans .env.local
  • Authentification admin : Mot de passe côté serveur (API route)
  • Règles Firestore : Lecture publique, écriture restreinte
  • Upload sécurisé : Validation des types de fichiers

Performance

  • SSR / SSG : Pages pré-rendues avec Next.js
  • Code splitting : Chargement dynamique des composants
  • Images optimisées : Compression automatique Cloudinary
  • Fonts locales : Pas de requêtes Google Fonts
  • Lazy loading : Composants 3D chargés à la demande
  • Tailwind purge : CSS non utilisé supprimé au build
